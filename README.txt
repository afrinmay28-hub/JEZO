JEZØ Professional Website Starter

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all 3 files in the same folder.
2. Open index.html in a browser.
3. Replace the demo product blocks with your real product images later.
4. Connect a real payment provider/backend only after the frontend is ready.

This starter intentionally uses no external libraries, so the basic website does not depend on a CDN or external CSS/JS service.
